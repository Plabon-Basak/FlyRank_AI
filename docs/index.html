1. Introduction / Problem Statement

Content teams often have more pages available for review than they can investigate manually. A useful machine learning system does not need to automatically change content to create value; it can instead help a reviewer decide where limited investigation time should be spent first.

This capstone focuses on that decision-support problem. The objective is to use historical search-performance signals to produce a ranked list of pages that deserve additional human investigation because their observed performance profile is associated with a severe decline in the exposed future window.

Research question:

Can historical search-performance signals identify pages that are likely to experience a meaningful decline or recovery opportunity in a future period, allowing content reviewers to prioritize pages for investigation?
Decision supported: Which pages should a content or SEO reviewer investigate first?

Intended output: an opportunity score, priority level, reason codes, and a recommended review action.

Scope

The analysis is intentionally limited to the supplied decline/recovery example lane. It should not be interpreted as evidence that the model generalizes to every page, website, search engine, industry, or future period.

The exposed impression windows were used to calculate percentage change:

An initial inspection showed that thresholds of 20% and 30% decline did not separate the sample because every row satisfied those thresholds. A 50% decline threshold produced two usable classes and was therefore selected for the capstone target. 

target_severe_decline =
    impression_change_pct <= -50%
The 50% threshold is a modeling decision for this supplied example lane. It is not presented as a universal definition of content decline.

3. Methodology

Feature design

The model uses signals that can be interpreted as historical page or search-performance characteristics rather than using the forward outcome-window metrics themselves.

Feature groups include:

Keyword structure URL structure Title structure Content age Previous impressions Previous clicks Previous sessions Historical CTR Historical session rate Content type Analytics availability

Derived historical features

Several rate-based features were derived from the previous observation window:

  • Previous-window CTR
  • Previous-window session rate
  • Previous-window click rate
  • Log-transformed historical volume features

Leakage controls

The following types of fields were excluded:

  • The directly provided is_declining flag.
  • Precomputed recommendation or health flags.
  • Outcome-window impressions, clicks, and sessions.
  • Other 90-day aggregate performance variables whose temporal composition could not be established safely from the supplied example cut.
  • Fields that could encode the target through post-outcome or precomputed decision logic.

Models

Model Purpose
Rule-based baseline Establishes a simple ranking using inverse percentile ranks of previous impressions, clicks, and sessions.
Logistic Regression Provides an interpretable linear probability model with balanced class weighting.
Histogram Gradient Boosting Tests whether nonlinear feature interactions improve ranking quality over the simple baseline.

Validation design

Because the supplied example data does not expose a usable calendar date for every row, a chronological train/test split could not be justified. Instead, the analysis uses an 80/20 stratified random split with a fixed seed of 42.

The same validation set is used for the rule-based baseline and both machine learning models so that the comparison is made under identical evaluation conditions.

Evaluation metrics

  • ROC-AUC: overall ranking discrimination.
  • Average Precision: precision-recall performance, particularly useful when evaluating a positive opportunity class.
  • Precision@10%: how concentrated severe-decline cases are among the highest-ranked 10% of pages.
  • Recall@10%: the proportion of severe-decline cases captured by the highest-ranked 10%.

Interpretation

The preferred model is selected using Average Precision because the practical objective is not simply to classify every page correctly. The operational objective is to rank a limited review queue so that pages associated with severe decline are concentrated near the top.

Based on the notebook's final validation output, the strongest model was: HistGradientBoosting.

Its Average Precision was 0.9022, compared with 0.7716 for the rule-based baseline.

Result framing: The model is useful only to the extent that it improves prioritization over a simple historical-signal baseline on the same held-out validation set. The experiment does not establish causality.

5. Limitations & Honest Framing

Observed

  • The supplied example lane contains 56,253 rows and provides two exposed 30-day impression windows.
  • A 50% or greater impression decrease provides a usable binary target for this experiment.
  • The selected models can be evaluated consistently against a common held-out validation split.

Directional

  • Historical page and search-performance characteristics can be used to rank pages by their association with the severe-decline target.
  • A machine learning model can potentially improve review prioritization over a simple rule-based ranking.

Not established

  • The model does not prove that any feature causes traffic or ranking decline.
  • The model does not prove or reproduce a search engine's ranking algorithm.
  • The model does not prove that a content refresh will recover traffic.
  • The analysis does not establish generalization to unseen clients, industries, search engines, or future calendar periods.
  • Because usable calendar dates were not exposed for the supplied rows, the validation design cannot establish true future-time generalization.
Important: This should be used as a decision-support ranking system for human review, not as an autonomous content-change or search-ranking system.

Reason codes

  • LOW_HISTORICAL_VISIBILITY — historically low previous-window impressions.
  • LOW_HISTORICAL_CTR — historically low previous-window click-through rate.
  • LOW_HISTORICAL_ENGAGEMENT — historically low previous-window session activity.
  • RELATIVELY_NEW_CONTENT — relatively low content age within this sample.
  • MODEL_RISK_SIGNAL — elevated model score without one of the simpler rule-based reason codes dominating.

9. Conclusion

This capstone demonstrates a practical machine learning workflow for turning historical search-performance signals into a ranked content review queue. The central contribution is not an automated claim about search-engine behavior, but a repeatable framework for comparing a simple baseline against machine learning models under a common validation setup.

Within the supplied decline/recovery example lane, the final system produces a probability-based opportunity score, priority level, reason codes, and human review action. The result can therefore support a reviewer in deciding where to investigate first while keeping the final content decision with a human.

Future work should evaluate the system on genuinely time-separated releases, test generalization across independent datasets, calibrate probabilities, and measure whether model-assisted review actually improves downstream decision quality.
